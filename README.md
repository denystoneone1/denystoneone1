### 🧭 About me

I've been in IT since 2011. I started as a system administrator running Active Directory, then went deep into Linux and networking.

For years I was responsible for the IT of our 120-person office and its branches inside a large group of companies. Our part of the group ran its own independent infrastructure: its own domain, servers, network and security perimeter. That meant designing it, building it, keeping it running and moving it forward: from a classic Windows setup to Linux servers, containers, monitoring and automation, and from Hyper-V through VMware to Proxmox.

I like to try things hands-on and understand how they work from the inside.

Today I work remotely as an independent engineer.

### 🌐 What I do

- **Networks** - design and operation of LAN / WAN: L2 / L3 switching, routing, firewalls, site-to-site VPN between branches. Multi-vendor: Cisco, MikroTik.
- **Systems** - Windows Server & Active Directory, Linux, virtualization (Hyper-V, VMware, Proxmox), Docker.
- **Monitoring & automation** - Zabbix, Prometheus, Grafana, Ansible, scripting in Bash, Python and PowerShell.
- **Security** - hardening, audits, vulnerability assessment. Now training on TryHackMe.

### 🛠 What I build

As a long-time user of service-desk systems, I knew exactly what was missing in them. So I built my own: a **CRM for service companies** that handles requests, clients, sites and SLAs, with a web app, a mobile app and the infrastructure it runs on.

It's already used in production by two companies and keeps growing: many ideas are still on the roadmap.

*Next.js · TypeScript · PostgreSQL · React Native · Go · Docker*

### 🎯 Where I'm heading

**Infrastructure architecture and information security.** These are areas where a deep understanding of real systems matters most, and where AI makes an engineer stronger rather than replacing one.
